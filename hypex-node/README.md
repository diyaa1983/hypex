# Hypex Node — الغلاف الكامل

كل شاشات وتقارير قائمة النظام على **Node.js** (تصميم 2027).

## التشغيل

```bash
cd hypex-node
npm start
```

**http://127.0.0.1:3000**

| | |
|---|---|
| كل الشاشات | `/menu` |
| لوحة التحكم | `/app` |

مبيعات · مشتريات · عملاء · موردين · مندوبين · مستودعات · محاسبة · موظفين · نظام · هاتف · مؤشرات الرئيسية
