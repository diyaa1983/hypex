================================================================================
  Hypex — فتح النظام من خارج الشبكة (الإنترنت / الموبايل)
================================================================================

الخريطة الصحيحة للوصول
----------------------
  الإنترنت  →  IP عام للراوتر :80
           →  Port Forward إلى جهاز السيرفر :80 (Apache)
           →  Apache يوجّه /hypex إلى Node على 127.0.0.1:3000
           →  الرابط:  http://PUBLIC_IP/hypex


خطوات سريعة على جهاز السيرفر
------------------------------
  1) شغّل Apache (XAMPP) و MySQL
  2) شغّل Node:
       deploy\HypexNode-Start.cmd
  3) افتح جدار الحماية كمسؤول:
       deploy\open-external-firewall.cmd
  4) تشخيص سريع:
       deploy\check-external-access.cmd
  5) على الشبكة الداخلية تأكد أن هذا يعمل:
       http://192.168.x.x/hypex


إعداد الراوتر (مثال Huawei HG8145V5)
------------------------------------
  1) ادخل واجهة الراوتر: http://192.168.1.1
  2) ثبّت DHCP Reservation (IP ثابت) لجهاز السيرفر
     - يُفضّل كابل Ethernet إن وُجد (مثال شائع: 192.168.1.159)
  3) Port Mapping / Virtual Server / NAT:
       Name:        Hypex
       Protocol:    TCP
       External:    80
       Internal IP:  IP الجهاز (مثال 192.168.1.159)   ← ليس 127.0.0.1
       Internal:    80
  4) احفظ وأعد تطبيق الإعدادات
  5) لا تفتح المنفذ 3306 (MySQL) ولا 3000 للإنترنت


كيف تختبر بشكل صحيح
--------------------
  - من بيانات الموبايل (ليس Wi‑Fi المنزل):
      http://PUBLIC_IP/hypex
  - سكربت التشخيص يعرض PUBLIC_IP الحالي
  - من داخل المنزل غالباً لا يفتح IP العام (NAT loopback) — لا تبنِ حكمك على ذلك


أخطاء شائعة
------------
  أ) استخدام IP عام قديم
     كان سابقاً: 176.29.176.192 (قد يكون تغيّر)
     تحقق دوماً من check-external-access أو الموقع: https://api.ipify.org

  ب) Port Forward يشير لـ IP خطأ
     الجهاز قد يكون 192.168.1.157 (Wi‑Fi) أو 192.168.1.159 (Ethernet)
     ثبّت IP واحد فقط في الحجز + التوجيه

  ج) Apache أو Node متوقف
     بعد إعادة تشغيل الجهاز شغّل:
       XAMPP Apache + MySQL
       deploy\HypexNode-Start.cmd
     (أو خدمة الإقلاع إن ثُبّتت)

  د) جدار حماية Windows على Public
     open-external-firewall.cmd يفتح TCP 80 لكل الملفات الشخصية

  هـ) CGNAT من مزود الإنترنت
     إذا كان الـ Port Mapping مضبوطاً والـ Firewall مفتوحاً ولا يزال
     لا يوجد وصول من بيانات الموبايل — المزود قد يحظر الوارد أو يستخدم CGNAT.
     الحل: IP عام ثابت من المزود، أو نفق عكسي (Cloudflare Tunnel / VPN).


الأمان (مهم إن فُتح الإنترنت)
-----------------------------
  - كلمات مرور قوية لحسابات النظام
  - لا تفتح MySQL أو منفذ 3000 للعالم
  - يُفضّل لاحقاً HTTPS + VPN بدل فتح 80 علناً على المدى الطويل


روابط مساعدة
------------
  داخلي:   http://localhost/hypex
  LAN:     http://IP_الجهاز/hypex
  خارجي:  http://PUBLIC_IP/hypex
  فحص:     deploy\check-external-access.cmd
  Firewall: deploy\open-external-firewall.cmd
  Node:    deploy\HypexNode-Start.cmd
