# تطبيق المندوب (Flutter APK)

## ماذا يفعل التطبيق
- تسجيل دخول بمستخدم مجموعة **MOBILE** (يربطه النظام بمندوب).
- **طلب شراء عميل**: حفظ/تعديل **مسودة فقط** — الاعتماد من سطح المكتب.
- ملخص حساب Oracle أسفل اختيار العميل (مدين / دائن / مستحق / شيكات).
- **كشف حساب عميل Oracle** بنفس بيانات تقرير النظام + طباعة بلوتوث 80mm.
- تتبّع موقع تلقائي حسب إعدادات النظام (مثال كل 10 ثوانٍ).

## إعداد النظام (المدير)
1. أنشئ مستخدماً في مجموعة `MOBILE` واربطه بمندوب.
2. امنح الصلاحيات: `m_customer_orders`, `m_party_statement`, وغيرها حسب الحاجة.
3. **إعدادات GPS**: شاشة `gps_tracking_settings` أو `/system/gps-settings`
   - تفعيل التتبّع + التشغيل التلقائي
   - مدة الإرسال (10/15/30/… ثانية)
   - إلغاء «السماح للمستخدم بإيقاف التتبّع» حتى لا يوقفها المندوب
4. تتبّع المندوبين: `/system/gps-tracker` و `/system/user-locations`
5. اعتماد الطلبات: `/sales/orders/approve`

## إعداد التطبيق على الهاتف
1. أول تشغيل: أدخل عنوان السيرفر (مثال `https://your-domain.com` أو `http://IP/hypex`).
2. سجّل دخول باسم مستخدم المندوب وكلمة السر.
3. الإعدادات للمندوب العادي: طابعة بلوتوث + حالة الموقع (قراءة).
4. **المستخدم الرئيسي** (ADMINS): فك قفل لتعديل عنوان السيرفر أو خدمة التتبّع إن سُمح من النظام.

## بناء APK (Windows)

إذا فشل البناء بسبب ذاكرة Java، خفّض في `android/gradle.properties`:

`org.gradle.jvmargs=-Xmx2G ...`

وتأكد من وجود JDK 17+ و`JAVA_HOME`.

```powershell
cd c:\xampp\htdocs\Hypex\mobile-flutter
flutter pub get
flutter build apk --release
```

الملف الناتج عادةً:

`mobile-flutter\build\app\outputs\flutter-apk\app-release.apk`

لتقسيم حسب المعمارية:

```powershell
flutter build apk --release --split-per-abi
```
